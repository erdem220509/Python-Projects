# Day #2 — Student Grade Manager 🎓

A simple Python program for managing students and their grades.

## Features

* Add students and their grades
* Calculate each student's average
* Assign letter grades from A to F
* View all students and their grades
* Find the student with the highest average
* Handle invalid user inputs

## Concepts Practiced

* Functions
* Lists and dictionaries
* Nested data structures
* `while` and `for` loops
* `if / elif / else`
* `try / except`
* Input validation
* Working with `None`

## How to Run

```bash
python main.py
```

## Example

```text
=== STUDENT GRADE MANAGER ===

1. Add student
2. View students
3. Show top student
4. Exit
```
